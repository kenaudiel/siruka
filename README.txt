SIRUKA - Halaman Beranda

File:
- beranda.php
- assets/css/beranda.css
- assets/js/beranda.js

Pemasangan:
1. Letakkan beranda.php di folder utama project, sejajar dengan halaman PHP lainnya.
2. Salin beranda.css ke assets/css/.
3. Salin beranda.js ke assets/js/.
4. Jalankan Laragon lalu buka http://localhost/Project/beranda.php (ganti Project sesuai nama folder).

Catatan: angka statistik dan jadwal merupakan data contoh statis. Halaman belum terhubung ke database. File ini menggunakan beranda.php agar index.php yang mungkin dipakai sebagai halaman login tidak tertimpa.
